# TP1 - Análisis de cianinas

Este repositorio contiene los datos experimentales y los códigos desarrollados en Python para el análisis de los espectros de absorción de las familias OXO-cianinas y TIA-cianinas, utilizando los modelos de pozo infinito y pozo finito.

## Contenido del repositorio

### Datos experimentales

- **`TP1_oxi.xlsx`**: contiene los datos experimentales correspondientes a las OXO-cianinas.
- **`TIAcianinas_datos_correctos.xlsx`**: contiene los datos experimentales correspondientes a las TIA-cianinas.

### Códigos y modelos

Los códigos están organizados en notebooks de Jupyter (`.ipynb`), separados según la familia de cianinas y el modelo utilizado.

- **`oxi.ipynb`**: contiene los ajustes y resultados correspondientes al modelo de pozo infinito para las OXO-cianinas.
- **`tia_cianinas.ipynb`**: contiene los ajustes y resultados correspondientes al modelo de pozo infinito para las TIA-cianinas.
- **`oxi_finito.ipynb`**: contiene los ajustes y resultados correspondientes al modelo de pozo finito para las OXO-cianinas.
- **`tia_cianinas_pozo_finito.ipynb`**: contiene los ajustes y resultados correspondientes al modelo de pozo finito para las TIA-cianinas.



Los datos experimentales y los códigos incluidos corresponden al material utilizado para el análisis y la obtención de los resultados presentados en el informe.
